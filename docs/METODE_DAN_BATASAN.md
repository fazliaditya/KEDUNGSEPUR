# Dasar data dan batasan SAPA KEDUNGSEPUR 2045

- Sumber utama data spasial: ZIP penelitian KEDUNGSEPUR dan keluaran Notebook 01–06 dalam percakapan ini.
- Tanggal kajian: LULC aktual/rekonstruksi 2010, 2015, 2020; proyeksi GeoSOS-FLUS 2045.
- Luas ekspansi bruto 2020–2045: 899,7696 km²; unit SOM 4.931 grid, model kandidat SOM 6×6 k=3 seed 42.
- Tiga tipologi: (1) vegetasi intensif dataran tinggi, (2) dataran rendah berintensitas rendah, (3) perkotaan berakses tinggi. Interpretasi bersifat sementara.
- Cakupan data bahaya pada ekspansi: banjir 45,0% dan longsor 96,6% (bukan proporsi wilayah berbahaya).
- Irisan layer kawasan lindung: 12,6011 km²; status hukum dan jenis zonasi belum dipastikan.
- Model proyeksi 2045 dan keterangan nilai kelas `Forest` memerlukan verifikasi mendalam sebelum digunakan sebagai rekomendasi tata ruang definitif.
- LULC ditampilkan dalam PNG berukuran 1600×958 piksel sesuai georeferensi overlay dari hasil pengolahan. Identifikasi interaktif dilakukan pada piksel PNG warna-kategorikal, tidak sama dengan pengambilan nilai piksel raster asli pada resolusi native.
- `data/area_studi.geojson` adalah area yang direpresentasikan dalam data kajian; **bukan garis KSN resmi** dari Perpres No. 60 Tahun 2022.
- Batas kabupaten/kota tidak ditampilkan; garis hitam menunjukkan area studi model, bukan delineasi KSN resmi.

Penggunaan peta ini ditujukan untuk eksplorasi skenario dan komunikasi hasil penelitian, bukan untuk penetapan izin/zonasi.
